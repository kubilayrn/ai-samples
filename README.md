## 🧠 Temel Yapay Zeka Terimleri Sözlüğü

Bu projede sıkça geçecek bazı temel kavramlar ve basit açıklamaları:

| Terim              | Basit Açıklaması                                                                                                       |
| :----------------- | :--------------------------------------------------------------------------------------------------------------------- |
| **LLM**            | Metin anlayıp üretebilen dil modeli (Large Language Model)                                                             |
| **Token**          | Modelin metni işlerken böldüğü ve kullandığı en küçük parça/kelime parçacığı                                           |
| **Prompt**         | Modele verdiğin komut, talimat veya girdi                                                                              |
| **Context Window** | Modelin aynı istekte (tek seferde) işleyebildiği maksimum bağlam/bellek miktarı                                        |
| **Embedding**      | Metnin anlamını yapay zekanın anlayabileceği sayısal vektörlere dönüştürme                                             |
| **RAG**            | Dış kaynaklardan (veritabanı, belge vb.) bilgi bulup modelin yanıtına zenginlik katma (Retrieval-Augmented Generation) |
| **Agent**          | Modelin kendi başına kararlar alıp araçlar (kod, arama vb.) kullanarak karmaşık görevler yürüttüğü sistem              |
